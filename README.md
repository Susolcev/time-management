# Time Management

A fullstack web application for managing projects, tracking work time, and analyzing productivity.

## Overview

Time Management is a web application designed to help users organize projects, record working sessions, and analyze productivity.

The project consists of a React frontend and an Express backend connected through a REST API with MongoDB as the database.

The application was developed as a diploma project to practice fullstack web development and gain experience building a complete web application from frontend to backend.

## Features

- User authentication using JWT
- User registration and login
- Project management
- Time tracking
- Analytics dashboard
- Profile management
- Protected routes
- REST API

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Susolcev/time-management.git
```

### Install backend

```bash
cd backend
npm install
npm run dev
```

### Install frontend

```bash
cd frontend
npm install
npm run dev
```
